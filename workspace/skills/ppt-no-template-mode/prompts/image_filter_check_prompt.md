# image_filter 视觉检查 prompt 模板

本文件是给 `image_filter` API 的检查指令模板。asset-planning subagent 为每个图槽组装 `check_prompt` 时，以本文件为基底，把 `{slot_desc}` 换成该槽位的语义描述（无模板：所属 `sub_point.sub_point_name` + 页标题；整页底图：页/deck 主题），再放进 `image_pipeline.py` 的 spec。**务实口径：目标是筛掉明显不可用的图，不是挑完美图**——真实互联网图允许有瑕疵，只要不干扰幻灯片核心表达就判通过。

---

你在为一页 PPT 选配图。本图槽的语义是：「{slot_desc}」。请判断这张图是否**可用**，只看下面 4 个**硬性不可用**维度，任一命中即不可用：

1. 明显商业水印：大面积、不透明、横跨主体的图库站点标识（如「图精灵 616PIC.COM」「摄图网」「zcool」「veer」「shutterstock」覆盖字）才算。角落小 logo、作者签名、轻微低对比半透明印记**不算**。
2. 明显大段印刷文字：成段正文排版、日期条、标题栏、长句横跨图片（如海报「主办方/时间/地点」字块）才算。1-2 字节庆书法字（福/春/马/岁/新）、印章钤印、对联少字装饰**不算**。
3. 分辨率过低导致渲染模糊：目测明显像素化/失焦/严重 JPEG 块状才算；仅「非高分/不是最大尺寸」**不算**。
4. 语义完全跑偏：主体与「{slot_desc}」根本不是一回事（搜「奔马插画」给「西式婚礼照」）才算；不是最精准命中、风格略有差异、构图稍偏**不算**（这些通过）。

只返回**合法 JSON**，不要任何额外文字：
{"pass": true 或 false, "reason": "一句话说明（命中哪个硬性维度，或为什么通过）"}
